Chapter 1: Basics of Information Technology

Important Questions

1. Define IT.

Information Technology is the use of computers, software and networks to collect, process, store and share information.

2. What is ICT?

ICT means Information and Communication Technology. It helps people manage and communicate information.

3. Differentiate between data and information.

Data means raw facts and figures. Information is processed data that has meaning.

4. What is hardware and software?

Hardware consists of physical computer parts. Software consists of programs and instructions.

5. Differentiate between RAM and ROM.

RAM is usually volatile working memory. ROM is non-volatile memory that retains its contents without power.

6. Explain LAN, MAN and WAN.

LAN covers a small area, MAN covers a metropolitan area, and WAN covers a large geographical area.

Chapter 2: Introduction to DBMS

1. What is a database?

A database is an organised collection of related data.

2. What is DBMS?

DBMS stands for Database Management System. It is software used to create, manage and retrieve data from databases.

3. Define table, field and record.

A table stores related data. A field is a column. A record is a row containing information about one item or person.

4. What is a primary key?

A primary key uniquely identifies each record in a database table.

5. What is a foreign key?

A foreign key refers to a key in another table to connect related data.

6. State four advantages of DBMS.

It reduces duplication, improves consistency, makes searching easier and supports access control.

Chapter 3: Impressive Web Designing

1. What is HTML?

HTML stands for HyperText Markup Language. It is used to structure webpage content.

2. What is a website?

A website is a collection of related webpages available under a common domain.

3. What is a hyperlink?

A hyperlink is a clickable link to another webpage, file or location.

4. What is the difference between a tag and an attribute?

A tag defines an HTML element. An attribute gives additional information about that element.

Basic HTML Program

Chapter 4: Cyber Law

1. What is cyber law?

Cyber law covers legal rules relating to computers, digital information, online communication and electronic transactions.

2. What is cybercrime?

Cybercrime is an unlawful act in which a computer or digital network is the target or tool of the offence.

3. What is phishing?

Phishing is a deceptive attempt to trick people into revealing private information by pretending to be trustworthy.

4. What is cyber ethics?

Cyber ethics means behaving responsibly, respectfully and fairly while using computers and the Internet.

5. Write four cyber safety rules.

Use strong passwords, never share OTPs, check links before clicking, and keep your devices updated.

6. What is the IT Act, 2000?

India's Information Technology Act, 2000 provides a legal framework for certain electronic records, electronic transactions and specified cyber offences.

Examples of Cybercrime

  • Phishing and online fraud
  • Identity theft
  • Unauthorised access
  • Cyberbullying
  • Malware
